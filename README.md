## 简介

琴阶 · PianoStep是一款为**零基础初学者**设计的 Android 钢琴练习应用。

它把学习过程拆成一个个短小的小课程，像闯关一样逐级推进——每次只专注一个小目标，练完立刻能看到结果。不要求你懂乐理，也不需要额外设备，打开就能弹。

安装包约 **210 KB**，体积轻量，下载和安装都不占什么时间。

## 功能特性

**练习方式**

- **跟弹练习**：界面左右铺满全屏，跟弹过程中实时给出「完美 / 良好」判定，练习结束即时反馈完成度
- **自由弹奏**：不受课程约束，随手弹奏、熟悉手感

**声音与键盘**

- 多音色可切换，选中态采用干净的玻璃质感样式
- 和弦状态实时提示，随时知道自己正在按什么
- 键盘高度支持 **5 档调节**，手机端自动预留状态栏安全边界，高档位下琴键也不会被裁切

**作品与分享**

- 一键录制弹奏，录制结束弹出专属命名窗口，可以为作品单独取名
- 导出的音频直接以作品名输出，不需要事后手动重命名
- 支持分享到 WeChat等常用应用
- 「最近作品」以卡片形式集中管理，日期与名称垂直居中对齐，一目了然
- 个人成长报告，直观了解你的一切变化
- 全局卡片式绘制，一键总结分享你的一切变化

## 下载与安装

### 推荐：在线下载页

在手机上打开 **[wdy2013.github.io/PianoStep](https://wdy2013.github.io/PianoStep/)**，页面提供两种下载方式并附安装指引，**扫码或直接点开即可**。

### 方式一：迅雷云盘

- 链接：<https://pan.xunlei.com/s/VP470L3hJlm21YPqNzSp9V4KA1?pwd=3b2e>
- 提取码：`3b2e`（已包含在链接中，打开即可）
- 国内访问更稳定，适合网络环境不佳时使用

### 方式二：GitHub Release 直链

- 前往 [Releases](https://github.com/wdy2013/PianoStep/releases/latest) 下载最新的 `PianoStep-x.x.x-release.apk`

> **提示**：此通道由 GitHub 托管，国内部分网络可能出现响应延迟、下载缓慢或需重试的情况，属于正常现象。若长时间无响应，建议改用迅雷云盘。

### 安装步骤

1. 下载 `PianoStep-x.x.x-release.apk` 到手机
2. 点击安装包，若系统提示限制，选择「设置」并允许当前浏览器或文件管理器安装应用
3. 返回安装界面点击「继续安装」，安装完成后即可开始练习

> 首次安装需授权「安装未知来源应用」，这是 Android 对非应用商店安装包的标准限制。
